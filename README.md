# GAME TROLL — Backend v2

این نسخه، پنل مدیریت و سفارش‌های فایل GAME TROLL را به API و دیتابیس SQLite متصل می‌کند.

## امکانات
- API واقعی برای بازی‌ها، پک‌ها، اخبار و آموزش‌ها
- ورود مدیر از طریق سرور، نه رمز داخل HTML
- افزودن، ویرایش و حذف محتوا از پنل مدیریت
- ثبت سفارش در دیتابیس
- تأیید، رد و لغو دسترسی سفارش توسط مدیر
- کش محلی فقط به عنوان حالت پشتیبان در صورت قطع سرور

## اجرا
Node.js 20+
```bash
npm install
npm start
```
سپس:
`http://localhost:3000`

برای محیط واقعی، ADMIN_PASSWORD و SESSION_SECRET را حتماً تغییر بده.


## شروع سریع

### Windows
روی `start.bat` دوبار کلیک کن.

### Android / Termux یا Linux
داخل پوشه پروژه:
```bash
npm install
npm start
```

بعد مرورگر را روی:
`http://localhost:3000`

باز کن.

### وضعیت
این پروژه برای اجرای Backend محلی آماده شده است. برای انتشار عمومی، در مرحله بعد باید روی یک هاست/سرور Node.js مستقر شود و رمز مدیر و SESSION_SECRET تغییر کند.


## انتشار آنلاین پیشنهادی
برای دیتابیس آنلاین، این نسخه از `DATABASE_URL` پشتیبانی می‌کند و می‌تواند به PostgreSQL/Supabase وصل شود. در حالت توسعه، اگر `DATABASE_URL` تنظیم نشده باشد، SQLite محلی استفاده می‌شود.

برای Supabase، Connection String را از بخش Connect بردار و به‌عنوان `DATABASE_URL` در سرور تنظیم کن. برای یک بک‌اند طولانی‌مدت، حالت Session Pooler مناسب است.
